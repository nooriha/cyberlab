# CyberLab

## درباره نشریه

CyberLab نشریه‌ای دانشجویی است که با هدف آشنایی ساده‌تر دانشجویان با مفاهیم امنیت سایبری منتشر می‌شود.  
شماره اول به موضوع حملات انکار سرویس توزیع‌شده (DDoS) اختصاص دارد.
